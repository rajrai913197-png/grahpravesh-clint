# Grah Pravesh Client — Frontend Structure

This package contains the planned React + Vite frontend file structure for the public website and Guest, Host, and Admin panels.

Most feature files are intentionally empty placeholders, as requested. Implement features gradually by adding components and page code.

## Run
1. Open this `client` directory in VS Code.
2. Run `npm install`.
3. Run `npm run dev`.

## Environment
Copy `.env.example` to `.env` and update `VITE_API_URL` when the backend is ready.
